# arknights_en_voice_player

アークナイツの英語ボイスを再生し、英語・日本語のテキストを確認できるWebアプリです。英語ボイスを使ったディクテーション学習にも対応する予定です。

## 予定している機能

- 頭文字・レアリティ・職分・職業によるオペレーター検索
- キャラクター別の英語ボイス一覧と音声再生
- 英語・日本語テキストの表示
- お気に入りキャラクター・ボイスの保存
- テキストを隠したディクテーション
- ディクテーション進捗の記録

## 技術構成

- React
- TypeScript
- Vite
- React Router
- Oxlint

## 開発を始める

```bash
npm install
npm run dev
```

## チェック

```bash
npm run lint
npm run build
```

両方をまとめて実行する場合は、次のコマンドを使います。

```bash
npm run check
```

## ディレクトリ構成

```text
src/
├── components/  共通UI
├── pages/       ページ単位のUI
├── App.tsx      ルーティング
└── main.tsx     アプリの起動処理
```

## 実装予定の順番

1. オペレーター一覧と検索
2. ボイス一覧と音声再生
3. 英語・日本語テキスト表示
4. お気に入り
5. ディクテーション
6. 学習進捗の保存
